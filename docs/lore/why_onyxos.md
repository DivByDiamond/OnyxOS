# Почему OnyxOS

Мы решили написать свой проект с нуля - для опыта.
Не для замены или конкуренции с Linux/Windows/BSD, а просто для души.

Мы увидели мод OC2R (Minecraft, NeoForge) с эмуляцией RISC-V и решили сначала сделать просто дистрибутив для него,
но потом ушли в более низкоуровневые вещи.

# загрузчик живёт отдельно: OnyxBoot (https://github.com/DivByDiamond/OnyxBoot)

# а так же отдельно ядро OnyxKernel (https://github.com/DivByDiamond/OnyxKernel)

сам OnyxOS это смесь загрузчика, ядра и встроенных программ с драйверами для базовой работы

в целом вам ничего не мешает запустить его и на обычном одноплатном пк по типу "Milk-V Duo S" на 512 мб озу (не реклама, просто совет)

теоретически вы можете сделать свой "дистрибутив" на основе ядра и загрузчика (либо использовать другой загрузчик, как пример u-boot)
