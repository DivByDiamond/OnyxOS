Known Issues

Current as of 2026-11-18. Only open limitations are listed here. Closed items live in docs/dev/roadmap.md, OnyxKernel/todo.md and docs/history/; anything done is not copied back here.

OnyxKernel

LimitationWhereWhat remains
Blocking `recv``kernel/src/net/tcp`There is no per-socket wait queue, so applications poll; a blocking path without busy-poll is needed
TCP sends 536 bytes per segment`kernel/src/net/tcp`No IP fragmentation; raise MSS and honour the path MTU
Server sockets are root-only admin`kernel/src/net`User-space `listen`/`accept` are unavailable and the contract is not documented in the README
No TLSuserspace (`obrowse`)The browser stays HTTP-only
No dynamic kernel modules`kernel/src/fs/procfs``/proc/modules` lists built-in drivers only
Journal has no flush/barrier`kernel/src/fs/onyxfs`Guarantees cover ordered block writes; power loss and partial sectors are untested on OC2R/physical media (L6)
Glyph blit is per-pixel over MMIO`kernel/src/drivers/video/fb_term`Scroll/clear copy words, glyph output does not (L4)
Double buffering unverified`kernel/src/drivers/video/fb`Tearing on a live OC2R monitor has not been measured (L5)
URB/HCD layer has no consumer`kernel/src/drivers/bus/usb/hcd.rs`Needs USB core enumeration (descriptors, addressing, mass storage) or removal
`nanosleep` on rv32 non-smode`kernel/src/arch`Goes through SBI; a direct CLINT MMIO path plus `mtrap_32` is required
RV32 smode unsupportedbuildThat combination has no boot entry and is rejected explicitly; the supported matrix is RV32 default and RV64 default/smode
No EOF after RST`kernel/src/net/tcp/sock.rs``recv` reports `Err(Io)` rather than `Ok(0)` - deliberate, but applications must distinguish reset from FIN (L3)

Userland

LimitationWhereWhat remains
No GUI window manager/compositor/cursoruserspaceSeparate windows, z-order/clipping, click handling, richer widgets
No Java runtimeuserspaceClass loader, bytecode interpreter, JDK subset, GC, hello-world in QEMU/OC2R
Applications not run live`OnyxApps`osnake, otop, ochat, ochat-gui are covered by host tests; interactive runs in QEMU/with the mod are unconfirmed

OnyxCompiller

LimitationWhat remains
One input per `-c`Several translation units cannot be compiled in one invocation
Archives without an indexLazy linear extraction; `__.SYMDEF` is not read
No COMDAT/versioning/relaxation/section GCLinking neither drops dead sections nor handles symbol versions
`-e` accepts GLOBAL symbols onlyAn entry point cannot be a local symbol
PCREL relocations are not emittedThe compiler never produces them; the linker relies on absolute ones
Hard caps64 objects and 4 sections per object
Single pass, no optimisationNo IR: const propagation, DCE and loop folding are absent
C++ is a subsetNo multiple/virtual inheritance, RTTI/`dynamic_cast`, class templates, virtual destructors or full unwinding - see `OnyxCompiller/docs/STATUS.md`
Repeated full bootstrapStage-one self-hosting works; a full self-build cycle is not complete

OnyxOS

LimitationWhat remains
CI cannot see local commitsThe `Onyx.lock.json` pin is only usable after the components are pushed; otherwise a locked build on GitHub cannot fetch the revision
Two-language documentationThe English versions lag behind; regenerate them with `build-docs.sh` after editing `.md`
