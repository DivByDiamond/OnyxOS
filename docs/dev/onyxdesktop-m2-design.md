# OnyxDesktop M2 design: minimal working desktop

Утверждено владельцем 2026-11-21 («пили до мин состояния: waybar-подобный
стол, фото-виджеты, консоль, лаунчер по бинду, конфиг биндов»).
Спека v1: `onyxdesktop-design.md`. M2 не меняет v1-контракты (маркеры,
claim-дисциплина, managed-приложения); меняет состояние стола.

## Цель

Стол, на котором есть: панель с виджетами (часы/uptime, активное
приложение), фото-виджеты на фоне, консольный виджет (osh в рамке),
лаунчер-оверлей по кнопке. Всё настраивается через `/etc/desk.conf`.

## Состояния стола

```
desktop (bar + photo-виджеты, лаунчер скрыт)
  |-- bind[launcher] --> launcher overlay (список приложений)
  |       клик по пункту: spawn, wait, перерисовка desktop
  |       клик мимо / bind[launcher]: закрыть
  |-- bind[console] --> console overlay (рамка osh поверх стола)
  |       ввод идёт в pipe osh, вывод рендерится в рамке
  |       bind[console]: закрыть
  `-- autostart: как в v1 (spawn + wait)
```

Клавиатура: desk в desktop-состоянии держит TTY в raw-режиме
(`cfmakeraw`), читает байты через `poll(fd0, короткий таймаут)` в общем
цикле с мышью. Запуск managed-приложения восстанавливает termios (как
otablet `launch_snake`), по возврату снова raw. Win-клавиша в TTY не
приходит (ядро не маршрутизирует HID-коды): бинды по умолчанию
`launcher:esc`, `console:tab`; переназначаются в конфиге.

## Конфиг (расширение формата v1)

```
# desk.conf M2
panel_height=24
app=osnake
app=ochat-gui
bind=launcher:esc
bind=console:tab
photo=/users/root/wall.bmp,320,180
photo=/etc/desk-logo.bmp,540,560
```

- `bind=<action>:<key>`: action ∈ {launcher, console}; key ∈ {esc, tab,
  enter} ∪ печатаемые ASCII. Неизвестный action/key игнорируется с
  предупреждением в stderr (как неизвестные ключи v1). Дубли биндов:
  побеждает последняя строка. По умолчанию launcher:esc, console:tab.
- `photo=<bmp>,x,y`: до 4 фото; BMP 24/32-бита без сжатия, координаты
  клипаются по кадру; битый файл пропускается с предупреждением, стол
  не падает.

## Виджеты

- **Часы**: `clock_gettime(CLOCK_REALTIME)`: если год > 2020, на панели
  `HH:MM:SS`; иначе uptime `up M:SS` (монотонные часы). Обновление раз
  в секунду.
- **Активное приложение**: имя запущенного/последнего приложения в
  панели (v1 уже рисует, M2 позиционирует справа).
- **Фото**: декодер BMP (24-bit BGR, 32-bit BGRX, bottom-up), blit через
  общий `put_px` (клип гарантирован). Один декодер, один путь кода.
- **Консоль**: `pipe` ×2, `_onyx_spawn("/bin/osh", argv, 1)` с
  dup-нутыми концами; чтение через `O_NONBLOCK` + `poll`, рендер
  последних строк в рамке фиксированной геометрии (x,y из констант
  стола, строки по шрифту 5x7). Ввод в console-состоянии уходит в pipe
  osh (backspace/enter проксируются). osh закрывается по закрытию
  виджета (kill/waitpid).

## Архитектура кода (лимиты 200/4)

- `src/desk/`: desk.c (стейт-машина ≤200), desk.h, io.c, kbd.c (raw
  TTY + диспетчер биндов; швы в desk_io).
- `src/widgets/`: bar.c (панель+часы+uptime, шов clock в desk_io),
  bmp.c (+bmp.h), photo.c, console.c (+console.h).
- `src/ui.{c,h}`: как в v1; лаунчер-оверлей рисует в рамке
  (перерисовка desktop-фона под ним при закрытии).
- Тесты: `tests/native/{config,desk,kbd,widgets,console,bmp}/` —
  подпапки, ≤4 файла на папку; все системные вызовы через швы.

## Не-цели M2

- Переключение живых приложений (SIGSTOP) — M3, ждёт ядерной
  маршрутизации ввода.
- PNG/JPEG: только BMP (без внешних декодеров).
- Перетаскивание виджетов мышью: координаты только из конфига.
- Иконки приложений: текстовый список.
